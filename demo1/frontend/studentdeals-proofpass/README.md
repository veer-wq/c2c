# StudentDeals + ProofPass

Open this folder in VS Code.

Run:

npm install

Then:

npm run dev

Open the localhost URL shown by Vite (usually http://localhost:5173).

Flow:
1. Checkout page
2. Click "Verify with ProofPass"
3. Scan modal opens
4. "Simulate Success" -> success page
5. "Simulate Failure" -> failure page
6. "Try again" -> scan modal again
7. Close/cancel -> checkout page
