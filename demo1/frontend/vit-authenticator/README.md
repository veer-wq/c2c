# VIT Authenticator — React/Vite

## Run locally

1. Install Node.js (LTS) if you don't already have it.
2. Open this project folder in VS Code.
3. Open a terminal in the folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite, normally:
`http://localhost:5173`

## Implemented interaction

- Student Directory roster matches the supplied Figma screenshots.
- Clicking any **ISSUE PROOFPASS** button opens the credential-success screen/modal.
- Clicking **Close & Return to Roster** returns to the roster.
- The recipient registration number changes according to the student selected.
- Roster search/filter works.
