# ProofPass Wallet

Open in VS Code and run:

npm install
npm run dev

Then open the localhost URL shown by Vite.

Flow:
Wallet -> Scan QR to Verify -> Scanner -> click inside scanner frame to simulate scan -> Privacy Gate.

Scanner:
- X or Cancel -> Wallet
- Click scan frame -> Privacy Gate

Privacy Gate:
- Approve Request -> Wallet
- Reject & Close -> Wallet
